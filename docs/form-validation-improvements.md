# フォームバリデーション改善 & ファイルアップロード改善

## 📌 問題

### 1. バリデーションエラーの分かりにくさ
- 必須項目をすべて入力してもエラーメッセージが表示される
- どのフィールドにエラーがあるのか分からない
- エラーメッセージだけでは改善点が不明確

### 2. ファイルアップロード��動作しない
- ファイルを選択してもアップロードされない
- エラーメッセージが不明確
- ファイルが選択されているか分からない

---

## ✅ 解決策

### 1. バリデーションエラーの視覚化

#### 実装内容
- **エラーがあるフィールドに赤い枠を表示**
- **各フィールドの下にエラーメッセージを表示**
- **fieldErrors stateで管理**

#### 視覚的フィードバック

**Before（改善前）:**
```
[ タイトル入力欄 ] ← 普通の枠
❌ エラー: 入力内容に誤りがあります（どこ？）
```

**After（改善後）:**
```
[ タイトル入力欄 ] ← 🔴 赤い枠
⚠️ 求人のタイトルを入力してください

[ サマリー入力欄 ] ← 🔴 赤い枠
⚠️ サマリーは100文字以上で入力してください
```

#### 対応フィールド

- ✅ 会社名・店舗名
- ✅ 求人のタイトル
- ✅ サマリー（文字数カウントも色変更）
- ✅ 勤務時間 / 活動時間
- ✅ 報酬額
- ✅ 勤務地 / 活動場所
- ✅ 募集人数
- ✅ 業務内容 / 活動内容
- ✅ 勤務日 / 活動日
- ✅ 開始日・終了日
- ✅ 外部URL・タイトル

---

### 2. ファイルアップロードの改善

#### 実装内容

1. **詳細なログ出力**
   - ファイル選択時のログ
   - アップロード結果のログ
   - エラー時の詳細ログ

2. **エラーハンドリング強化**
   - 個別ファイルごとにエラー処理
   - 一部成功・一部失敗の対応
   - エラーメッセージの改善

3. **UX改善**
   - ファイル選択後のinputリセット
   - 最大件数到達時の警告表示
   - accept属性の拡張（MIMEタイプ追加）

#### コード例

```typescript
// Before
accept=".pdf,.png,.jpg,.jpeg"

// After
accept=".pdf,.png,.jpg,.jpeg,image/png,image/jpeg,application/pdf"
```

#### エラーメッセージの改善

**Before:**
```
❌ ファイルのアップロードに失敗しました
```

**After:**
```
✅ 2件のファイルをアップロードしました（1件失敗）
または
❌ 1件のファイルのアップロードに失敗しました
コンソール: Upload error: ファイルサイズは5MB以下にしてください
```

## 🧪 テスト方法

### 1. バリデーションエラーのテスト

```
1. 求人作成ページにアクセス
2. タイトルを空欄のまま「求人を作成」をクリック
3. ✅ タイトル入力欄が赤い枠で表示される
4. ✅ 「求人のタイトルを入力してください」と表示される
5. タイトルを入力
6. サマリーを50文字だけ入力して「求人を作成」をクリック
7. ✅ サマリー入力欄が赤い枠で表示される
8. ✅ 「サマリーは100文字以上で入力してください」と表示される
9. ✅ 文字数カウントが赤色で表示される
```

### 2. ファイルアップロードのテスト

```
1. 求人作成ページにアクセス
2. 「ファイルを選択」ボタンをクリック
3. PDFまたは画像ファイルを選択
4. ✅ ブラウザのコンソールに「Files selected:」ログが表示される
5. ✅ アップロード中...と表示される
6. ✅ 成功時「○件のファイルをアップロードしました」トースト表示
7. ✅ ファイル一覧に追加される

エラーケース:
- 6MB以上のファイル → ❌ エラーメッセージ表示
- 6件目のファイル → ❌ 「最大5件に達しています」
- 非対応形式（.docx） → ❌ エラーメッセージ表示
```

## 🔍 デバッグ方法

### ブラウザのコンソールで確認

```javascript
// ファイル選択時
File input changed: FileList { 0: File, length: 1 }
Files selected: [{ name: "example.pdf", type: "application/pdf", size: 123456 }]

// アップロード開始
Uploading file: example.pdf

// アップロード結果
Upload result: { success: true, url: "...", fileName: "...", fileType: "pdf", fileSize: 123456 }

// エラー時
Upload error: Error: ファイルサイズは5MB以下にしてください
```

### Supabase Storageの確認

1. Supabaseダッシュボードにアクセス
2. Storage → job-attachments バケット
3. アップロードされたファイルを確認
4. パスは `{userId}/{timestamp}_{random}.{ext}` 形式

---

## ⚠️ 注意事項

### Supabase Storageの設定

ファイルアップロードが動作しない場合、以下を確認：

1. **バケットの存在**
   - `job-attachments` バケットが作成されているか

2. **アクセス権限**
   - バケットポリシーで雇用主がアップロード可能か
   - 公開読み取りが有効か

3. **ファイルサイズ制限**
   - Supabase側の制限（デフォルト50MB）
   - アプリ側の制限（5MB）

### バリデーションのカスタマイズ

`src/lib/utils/job-form-validation.ts` でルールを変更可能：

```typescript
// サマリーの文字数を変更
if (trimmed.length < 50) { // 100 → 50に変更
  return { isValid: false, error: 'サマリーは50文字以上で入力してください' }
}
```

## 🎯 期待される効果

### ユーザー体験
1. **エラーの特定が容易**
   - 赤い枠でエラー箇所が一目瞭然
   - 具体的な改善方法が分かる

2. **入力の安心感**
   - リアルタイムで文字数確認
   - エラーが解消されたことが分かる

3. **ファイルアップロードの透明性**
   - アップロード状態が分かる
   - エラー時の原因が明確

### 開発者体験
1. **デバッグが容易**
   - 詳細なコンソールログ
   - エラー追跡が簡単

2. **拡張性**
   - 新しいフィールドへのエラー表示追加が簡単
   - バリデーションルールのカスタマイズが容易
